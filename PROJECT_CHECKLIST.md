# Pre-publication checklist

- [x] ETL preserves nulls and is runnable from repository root.
- [x] ETL uses one documented amount-cleaning rule.
- [x] Notebook and ETL share the same cleaning function.
- [x] Raw vs. cleaned `describe()` comparison is documented.
- [x] SQL loader is configurable through environment variables.
- [x] Local SQL Server settings are documented through `.env.example`.
- [x] SQL loader honors encryption and certificate settings from `.env`.
- [x] SQL loader environment settings are covered by a unit test.
- [x] SQL staging load is idempotent by default (`TRUNCATE`).
- [x] SQL loader validates required tables/columns before modifying staging and reconciles the final staging row count.
- [x] Schema creation is separated from data loading and checks.
- [x] Star-schema documentation matches the Power BI semantic model.
- [x] Currency handling does not claim unsupported FX conversion.
- [x] README metrics are reconciled to the full source dataset.
- [x] README explains what was solved, why, how, and where each layer fits.
- [x] Sample dataset included for reviewers.
- [x] Python tests included for ETL and SQL-loader validation.
- [x] Large datasets excluded from Git.
- [ ] Export a real final screenshot from Power BI Desktop (optional portfolio asset).
- [ ] Replace `<your-username>` in README after creating the GitHub repository.
